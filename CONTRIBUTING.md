# Contributing

Norless is licensed under the [GNU AGPL v3.0 or later](LICENSE). By contributing, you agree that your work is published under the same license.

## Sign off your commits

Every commit needs a `Signed-off-by` line: your statement that you have the right to contribute it, per the [Developer Certificate of Origin](https://developercertificate.org/).

```bash
git commit -s
```

## Never commit

Secrets, `.env` files, database files, dumps, user data, or copyrighted song lyrics and Bible texts.
