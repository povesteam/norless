# Norless manual

Norless shows your church's songs on the projectors, the musicians' tablets and the
stage TV, from one playlist. This manual is for the people who use it on Sundays.

The pictures come from `npm run screenshots` (public-domain hymns and made-up people).
A CI workflow will publish these pages with fresh pictures on GitHub Pages.

## Pages

1. [Your first Sunday](first-sunday.md): open the playlist, project, go live, blank.
2. [Logging in](logging-in.md): Google, an email link, or your phone.
3. [Playlists](playlists.md): make Sunday's playlist, add songs and dividers, print it.
4. [Songs](songs.md): find, edit and write songs, with chords and notes.
5. [On stage](stage.md): the musicians', singers' and stage monitor views.
6. [Screens](screens.md): screens with links, pairing a TV, the live stream.
7. [For owners](owners.md): members and roles, the features, screens and pages.
8. [The team](team.md): who does what each Sunday, who leads each song, the church's
   calendar.
9. [Offline at camp](offline.md): projecting from a laptop without internet.

## Features

Your community meets the new app a few features at a time. It starts like the old
Norless (Classic: one playlist, the projectors, start and end pages), and its owner
switches more features on in **More → Features**; everyone sees the same ones.

This manual starts with Classic. What a page shows beyond it appears once an owner has
switched that feature on.
