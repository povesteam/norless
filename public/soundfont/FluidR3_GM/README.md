# FluidR3_GM sounds

The piano (`acoustic_grand_piano-mp3`, C2 to C7) and 12 drum sounds (`percussion-mp3`) that notation blocks play with, served by Norless and downloaded only when someone presses play.

- FluidR3_GM, a General MIDI SoundFont by Frank Wen, licensed under [Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/).
- Rendered to mp3 by Benjamin Gleitzman's [midi-js-soundfonts](https://github.com/gleitz/midi-js-soundfonts), from <https://paulrosen.github.io/midi-js-soundfonts/FluidR3_GM/>.

The file names are the notes abcjs asks for: `<instrument>-mp3/<note>.mp3`, e.g. `C4.mp3`, `Db3.mp3`.
